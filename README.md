Indian Cities Data Analysis Using Python

Overview
This project focuses on analysing a dataset of 50 Indian cities using Python and Pandas. The dataset contains information such as city name, state, region, latitude, longitude and elevation.
The main objective of this project is to understand the dataset, perform data cleaning and transformation, handle missing values, and generate meaningful insights through data analysis.
Data visualization is also performed using Matplotlib to represent the results through bar charts and pie charts. These visualizations help in understanding and comparing city elevations and regional distributions.

Objectives
- To read and understand the dataset using Pandas.
- To explore the structure and data types of the dataset.
- To perform data transformation.
- To identify and handle missing values.
- To generate meaningful insights using data analysis.
- To visualize the results using bar charts and pie charts.

Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

Dataset Description
The dataset contains information about 50 Indian cities with the following attributes:
- City
- State
- Region
- Latitude
- Longitude
- Elevation (meters)

Expected Outcome
The project helps identify geographical patterns among Indian cities, compare elevations across different regions, and present useful information through data visualization.

Conclusion
This project provides practical experience in data analysis using Python. It helps in understanding how raw data can be processed, analysed and converted into meaningful insights using Pandas and Matplotlib.
